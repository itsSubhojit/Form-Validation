# Glass Morphism Form Validation

A modern, stylish sign-up form with validation and glassmorphism effect. This project demonstrates HTML, CSS, and JavaScript working together for a beautiful and functional user experience.

## Features
- **Glassmorphism UI:** Uses CSS for a frosted glass effect.
- **Form Validation:**
  - Full Name: Minimum 6 characters, letters and spaces only.
  - Email: Standard email format.
  - Password: At least 8 characters, with uppercase, lowercase, number, and special character.
  - Confirm Password: Must match the password.
- **Error Messages:** Clear, inline error messages for each field.
- **Password Visibility Toggle:** Click the eye icon to show/hide passwords.
- **Responsive Design:** Looks good on all screen sizes.

## File Overview
- **Form Validation.html**: The main HTML file containing the form structure.
- **Form Validation.css**: Styles for the form, including glassmorphism and responsive design.
- **Form Validation.js**: Handles form validation, error display, and password visibility toggling.

## How It Works
1. User fills out the form.
2. On submit, JavaScript validates each field using regular expressions.
3. If any field is invalid, an error message appears below the field.
4. If all fields are valid, a success message is shown and the form is cleared.
5. Users can toggle password visibility using the eye icons.

## Usage
1. Download all three files into the same folder.
2. Open `Form Validation.html` in your browser.
3. Try signing up with different inputs to see validation in action.

## Customization
- You can change the background image in the CSS file for a different look.
- Adjust regex patterns in the JS file to change validation rules.
